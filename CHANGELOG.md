## 1.2.14

- В «Универсальной вырезке» оставлены ровно два режима: «Влёт → вылет» и «Один маркер: подряд идущие треки».
- Удалён совмещённый режим из интерфейса.
- Режим «Влёт → вылет» вырезает весь фрагмент от начального CUE-маркера до конечного включительно.
- Режим одного маркера теперь повторяет исходную логику новостей: соседние CUE-треки, в названии которых встречается заданный текст, объединяются в один выпуск.
- Первый трек без заданного текста завершает блок; следующая серия совпадений создаёт следующий отдельный выпуск.
- Например `Новости` + `Новости погода` + `Музыка` + `Новости` дают два файла: первый содержит два подряд идущих новостных трека, второй — один.
- Сохранённое значение `same` из старых версий автоматически понимается как режим одного маркера; `combined` из 1.2.13 безопасно переводится в «Влёт → вылет».

## 1.2.13

- В «Универсальную вырезку» добавлен третий способ: «Совмещённый: влёт → вылет ИЛИ один CUE-трек».
- В совмещённом режиме одновременно задаются три маркера: начальный (влёт), конечный (вылет) и маркер одиночного CUE-трека.
- В одном и том же часовом CUE программа может вырезать часть выпусков по паре «влёт → вылет», а часть — как одиночные CUE-треки.
- Парная вырезка имеет приоритет: CUE-треки, находящиеся внутри найденной пары, повторно как одиночные не экспортируются.
- Если для выпуска нет завершённой пары «влёт → вылет», подходящий одиночный маркер всё равно может быть вырезан как один CUE-трек.
- Имена нескольких фрагментов внутри часа получают фактическую минуту начала, поэтому результаты не перезаписывают друг друга.

## 1.2.12

- В «Универсальной вырезке» режим с одним маркером больше не ищет второй такой же маркер.
- Новый смысл режима: каждый найденный CUE-пункт с заданным маркером вырезается как ровно один трек — от его `INDEX 01` до начала следующего CUE-трека.
- Если в одном часовом файле два выпуска с одинаковым названием, например «Новости» в 11:00 и 11:20, создаются два независимых файла с минутой фактического начала: `news_..._11-00.mp3` и `news_..._11-20.mp3`.
- Режим двух маркеров сохранён отдельно и работает строго как «влёт → вылет».
- Старое сохранённое значение режима `same` автоматически понимается как новый режим одного CUE-трека, поэтому существующие универсальные задания не ломаются.

## 1.2.11
- Добавлен новый модуль «Универсальная вырезка» для создания гибких эфирных заданий без правки кода.
- Одно задание может содержать несколько независимых источников/сетевых папок.
- Для каждого источника отдельно задаются название, папка MP3+CUE, часы обработки, сообщение перед отправкой и название итогового MP3.
